Evidence-based pity per pity group, derived on read, with colour cues.

## Tasks

Each task is one PR, in this order. Neither needs banner metadata: until
verified metadata defines pity groups, each banner category keeps its own count.

- [ ] Calculate pity per pity group, treating each group's stored rolls as
  complete and recalculating later rolls after older rolls are imported. Settle
  when and how pity is calculated first, and record it as a decision; the
  [statistics](../../architecture/statistics.md) proposal derives it on read.
  Show it in a Pity column. Pity counts every roll in the group, so filters and
  search never change it.
- [ ] Colour 5★ pity by closeness to soft pity, with thresholds per banner
  category (the mockup uses 1–49, 50–74 and 75+ as placeholders), from verified
  rules with their evidence recorded.

Colouring by 50/50 outcome needs featured items, so it belongs to
[0034 — Banner metadata](0034-banner-metadata.md).
