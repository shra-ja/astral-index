# 0025 — Third-party notices

Date: 2026-10-13
Status: Accepted

## Context

The release build ships about 350 Rust crates, the npm packages Vite bundles
into the frontend, and the Hanken Grotesk typeface. Their MIT, Apache-2.0, BSD,
ISC, Zlib, Unicode, MPL-2.0 and OFL licences require their notices to travel
with the binaries ([feature 0050](../../product/features/0050-about-and-notices.md)).
Many crates carry only a licence field, not a licence file, and dual-licensed
crates need one licence chosen. The notices must stay current as dependencies
change, without the check being skippable or silently incomplete.

## Decision

- **cargo-about for the crates.** `cargo about generate --format json --frozen`
  with `src-tauri/about.toml` lists the crates in the release dependency graph
  for Windows and Linux, leaving out build and development dependencies and the
  app's own unpublished crate. Licence texts come from each crate's sources, or
  from the SPDX texts cargo-about carries; `--frozen` keeps it off the network.
  For a choice such as `MIT OR Apache-2.0`, it takes the first accepted licence
  in the list's order, so MIT, listed first, gives the shortest notices.
- **rollup-plugin-license for the npm packages.** It reports the packages the
  production bundle actually contains, with their licence texts; it works with
  Vite's Rolldown bundler. The gate builds with `NODE_ENV=production` so the
  report matches the release, not a development build. The typeface reaches the
  bundle through CSS, so it is read from its `@fontsource-variable` package.
- **One accepted list.** `about.toml`'s `accepted` setting is the policy for all
  three sources: MIT, MIT-0, Apache-2.0 (also with the LLVM exception),
  BSD-2-Clause, BSD-3-Clause, ISC, Zlib, 0BSD, CC0-1.0, Unlicense, Unicode-3.0,
  MPL-2.0 and OFL-1.1. MPL-2.0 covers five crates Tauri uses to parse HTML and
  CSS, shipped unmodified; each notice links to the component's published
  source, as MPL-2.0 asks.
- **Generated by every build, never committed.** `npm run build`, which
  `tauri build` and the check run, first runs `npm run notices`. It writes
  `src-ui/src/assets/third-party-notices.json`, for the About dialog, and the
  plain-text `THIRD-PARTY-NOTICES` at the repository root, for distribution;
  both are gitignored, so they can never be stale. It fails, and so does the
  build, when a component has no licence text or a licence is outside the list.
  `tauri dev` serves the frontend without building it, so it needs no notices.
- **Shown in the About dialog.** The frontend loads the JSON through a lookup
  (`import.meta.glob`) that finds nothing rather than failing when the file is
  missing, so a development run says the notices come from builds. The notices
  are a chunk of their own, loaded when the notices view first opens, not part
  of the startup bundle.

## Alternatives and consequences

- **A first-party generator:** no new tools, but it would have to carry SPDX
  texts for crates without licence files and repeat cargo-about's licence
  detection.
- **cargo-deny:** checks licences against a policy, but produces no notice
  texts, so it would add a gate without the notices.
- **Committed and checked for staleness:** builds would need no extra tool, but
  the two files (about 750 KB) would hold the same texts twice, and every
  dependency bump would rewrite them in its pull request, where the licence
  policy, not the texts, is what a reviewer needs. Chromium (its credits page,
  for official builds), the Rust project (`COPYRIGHT.html`), GitHub Desktop
  (`licenses.json`) and Zed (`licenses.md`) all generate their notices during
  the build instead.
- cargo-about 0.9.2 is a pinned tool, installed with its `cli` feature in setup
  and CI, and every build needs it and the registry sources; generating takes
  about 7 seconds.
- The notices hold about 180 distinct texts for about 360 components: about
  350 KB as text and 400 KB as JSON.

## Evidence

- cargo-about's report on 2026-10-13: 347 crates under MIT, Apache-2.0,
  BSD-3-Clause, ISC, MIT-0, MPL-2.0, Unicode-3.0 and Zlib. The production
  bundle's report: 11 npm packages under MIT, ISC and Apache-2.0.
- Removing MIT from the list makes cargo-about fail with "failed to satisfy
  license requirements"; a mutation probe checks this.
